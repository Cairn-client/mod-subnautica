# Nitrox on Cairn

A fork of [SubnauticaNitrox/Nitrox](https://github.com/SubnauticaNitrox/Nitrox), the multiplayer mod for **Subnautica**, made to run on the [Cairn launcher](https://github.com/Cairn-client/launcher).

## What we changed

- A Cairn pack: the Nitrox release for Windows is published as a pack the launcher installs in the game's folder and updates.

The mod's own code and credits are its authors'. Everything else is as upstream; see [UPSTREAM.md](UPSTREAM.md) for the version this fork is based on and the release the pack carries.

## Play it

1. Install [Cairn](https://github.com/Cairn-client/launcher/releases/latest).
2. Open Subnautica in the Library, download the mod and press Play.

Each release of this repository is the pack the launcher downloads.
